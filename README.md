## About Project => Talent Faculty by Trueminds Innovations Ltd

Talent Faculty by Trueminds Innovations Ltd is an eLearning platform, built by Trueminds Innovations Ltd for the purpose of training and equipping young tech individuals with the required skills they need to progress in life.

This project aims to expand the Trueminds Innovations internship service to accommodate more interested participants while providing a more structured approach to operations, management, tracking, and communication. The goal is to foster a better learning and collaborative experience compared to our pilot phase (first cohort).

### The Problem

The previous management system primarily focused on administrative tasks, which included organizing interns' data, grading, responding to queries, tracking updates, sending bulk emails, managing communication channels (such as Slack), distributing certificates, and creating teams. However, feedback from learners and internal reviews indicated a need for a more structured and improved platform.

### The Proposed Solution

This project will address the identified issues by providing a comprehensive learning management system that
incorporates all necessary functionality, including:

<ol>
    <li>
        Course Management: Organizes content, video resources, and reading materials into structured learning paths.
    </li>
    <li>
        Assessments & Grading: Hosts quizzes, automated assignment activities, and submissions to evaluate learner comprehension
    </li>
    <li>
        Tracking & Analytics: Generates reports that allow administrators or instructors to see exactly how well learners are performing.
    </li>
    <li>
        Communication: Includes built-in messaging, discussion forums, and live video conferencing capabilities
    </li>
</ol>

### Business Value

The strategic benefits of this project include an improved overall experience for learners and interns, enhanced collaboration and information sharing, reduced inefficiencies in the current processes, better management and organization, and improved operational and delivery times. 


### Project Objectives
<ol>
    <li>
        Primary Objective: The objective of this project is to improve the overall learner experience and satisfaction by 75%. Build a platform that facilitates comprehensive collaboration between learners and the administration. Additionally, improved our process workflow by 50%, reducing communication delays, tracking, submission issues, and other bottlenecks. Enhanced collaboration and retention of learners measured through an increase in program completion rates compared to previous data.
    </li>
    <li>
        Secondary Objectives: Create an Improved LMS platform that allows real-time collaboration between interns, instructors, and administration.
    </li>
</ol>

## Contribution Guide
##### How to create PRs for this project
To make contribution to this project, [called PR => Pull Request], follow the instructions below:
<ul>
    <li>Create a new Branch</li>
    <li>Checkout to the new branch</li>
    <li>Work on your modification</li>
    <li>Push your code to GitHub</li>
    <li>Create a PR [you can also request for Review]</li>
    <li>Wait for your PR to be reviewed and merge</li>
    <li>Attend to comments and further modification requests</li>
</ul>

<ol>
    <li>
        When you finish setting up the project locally and you want to start working, simply run any of the following
        commands: <code>git branch <branch_name></code> or <code>git checkout -b "branch_name"</code>. Remember this
        should br run without the "<>" tags on the branch name.
    </li>
    <li>
        If you used <code>git checkout -b branch_name</code>, don't bother checking out to the new branch, because you
        are already on the new branch, otherwise, simply run <code>git checkout branch_name</code> [branch_name] is a
        placeholder for your preferred branch name.
    </li>
    <li>
        Edit the codes you want and add features required for your tasks
    </li>
    <li>
        When you are done working, push your code to git hub by running these command, don't forget.
        <ol type="a">
            <li><code>git add .</code></li>
            <li><code>git commit -m "commit message"</code> <em>you must include the "" before and after your commit
                    message</em></li>
        </ol>
        <ol><code>git push origin branch_name</code></ol>
        Once you finish these, your code will be uploaded, github will return a unique url for you to create your pull
        request from. <br>
        <br>
        Also you can leverage on the power of Visual Studio Code if you use VS for writing codes, by simply click on the
        three icon where you have total number of files changed, if your AI agent is active, it will suggest commit
        message, and simply click on commit.
    </li>
    <li>
        When you are done pushing, head over to github, and create a PR from your new branch into <code>staging</code>,
        and allow the reviewer review, also as added advantage you can add the review directly.
    </li>
    <li>
        Once your job is review and passes all necessary requirement, it will be merged into the staging branch for
        development testing, otherwise, comments will be left for you to treat
    </li>
    <li>
        if you have comments, fix the issues and reupload your new changes, that is updating the branch, if this
        satisfies the review your code will be merge, if not, more correction, until the final approval and merge.
    </li>
</ol>
